# 生成角色与场景

## 立绘、头像与属性配置

先从 `assets/ip-config.json` 取所需角色的 `visual`、`shared_morphology` 和 `style`，再查看对应立绘。将 `character_type` 与外貌一并展开到生成请求，让人格、姿势和身体结构符合设定。名字后必须跟可识别的外貌描述。

> 输出类型与尺寸 → 角色数量及每只的身份特征 → 姿势、表情与道具接触关系 → 地点、天气与光线 → 媒介和构图 → 本次文字要求。

变量只包含任务实际需要的内容，例如：

```json
{
  "characters": ["kaka", "pipi"],
  "purpose": "cover",
  "scene": "雨后的木栈桥",
  "action": {
    "kaka": "扶稳荷叶伞，站在岸边",
    "pipi": "坐在桥边，递出一杯茶"
  },
  "season": "初夏",
  "text": null
}
```

这是一次创作的输入片段，不是第二份 IP 配置。角色代码在生成前展开为主配置的描述，色值按字段引用取得；无需让用户理解内部代码。

换装时保留识别特征与身体比例。临时服饰应顺应短肢和圆胖体型，头饰与服饰可自然组合。需要透明全身时制作真正的 alpha 通道成品；内置纸底立绘不能直接当成透明素材。

同一组立绘或头像统一视角、体量、线条、纸感与光照。裁切预览时查看实际目标形状，确保头饰、嘴脸和关键道具可辨。用户要侧面、背面或标准三视图时，按正面参考推导新的视图，并将其说明为本次补充设计。

## 背景与封面

从配置中的世界场景选择和主题有关的生活动作，用动作表达含义：

| 主题 | 现有构图参考 | 可复用的表达 |
| --- | --- | --- |
| 规划与审查 | `assets/scenes/planning.webp` | 在岸边铺开地图，观察与核对 |
| 项目启动 | `assets/scenes/launch.webp` | 小船靠岸，解绳准备启程 |
| 进展周报 | `assets/scenes/weekly.webp` | 栈桥、水位与笔记，观察变化 |
| 复盘 | `assets/scenes/retrospective.webp` | 秋岸排列石子，回看与整理 |
| 团队随笔 | `assets/scenes/notes.webp` | 柳岸递茶，一段共同休息 |

主题变化时重新选择动作和环境。宽封面先按最终比例构图，让景色覆盖边缘；角色和关键动作进入裁切安全区。可复用原构图，也可重新生成，但不要把小图简单拉宽。

纸感来自画面中的纤维、线条和水彩层次，不用厚重噪点遮盖五官。画面内的工作物件以地图、笔记或生活道具表达；用户要求界面示意时再加入界面元素。

## GIF 与视频

先查看动作图集，需要理解速度、接触和循环时从索引读取原 GIF。原视频用于查看更完整的运动或重新剪辑，不能由静态关键帧声称已经验证。

用五个节点说明动作：起始姿态、预备、主体动作、反应、回到可衔接姿态。明确哪只做什么、爪子接触哪里、道具怎么运动；依据身体重心完成转头、伸展、弯腰、步法或互动。

日常动作的参考入口：

| 动作 | 核对重点 |
| --- | --- |
| 擦靴 | 刷子与靴面接触，靴子归属清楚，双角色配合 |
| 喝茶烫嘴 | 杯子靠近嘴、喝到茶、受烫后反应；不能只有杯子晃动 |
| 吃柚子 | 咬与缺口对应，嘴和爪的动作成立，头顶标记可辨 |
| 刷牙与泡泡胡子 | 牙刷接触、泡沫变化和擦嘴连续 |
| 伸懒腰打喷嚏 | 胸肩伸展、吸气、喷嚏与回落；果实运动有因果 |
| 擦桌挤成团 | 爪与桌面接触，两只相互挤压有身体位移 |
| 闪身步、踢球、哆嗦毛 | 重心、迈步、抬腿或毛发抖动驱动动作，头饰跟随身体 |

动作允许适度夸张，但头饰和道具应跟随具体运动。纸底、毛发线条、颜色与光照保持帧间稳定。遮挡时保留物体连续性；再次显露的位置应能由之前的运动解释。

交付前实际播放成品，检查主体动作可读、接触合理、无异常增肢、无整张贴图式抖动；循环任务另检查首尾衔接。检查真实文件的尺寸、时长、格式和大小；只有平台或用户要求体积上限时才按该上限压缩。

## 成品采用

复用压缩图时，其分辨率必须适合目标输出；高清、精细编辑和再次压缩优先取原件。生成失败时根据成品中具体的身份、动作或构图问题修订请求，避免累加与问题无关的描述。

交付图片、动画或视频，并按需附单独文案。若工具无法制作所要求的格式，说明当前实际产物与缺失步骤；提示词不等同于已经生成的资源。
