设计细节

主视觉采用 Three.js 绘制柔边样片，使用粗糙度、微弱凹凸纹理与柔和光照表达表面。控件保留为 HTML。

浮动工具条使用 CSS 半透明材质。下方控件以当前位置和速度计算临界阻尼弹簧，重新抓取不跳回起点。

系统或本页选择减少动效时，自动转动和释放惯性停止；直接拖动与键盘控制继续可用。

这是材质与交互的原创近似，不是 Apple 原生材质的复刻。
