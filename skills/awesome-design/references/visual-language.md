# 视觉规则

本文件给出可实现的起点。标为“实测”的值来自参考 SVG；其余数字是本技能的建议，不是 Apple、Vercel 或 Claude 的官方参数。

## 场景与表面

| 场景 | 字体与布局 | 材质 | 适用边界 |
| --- | --- | --- | --- |
| 图解、学习、阅读 | 展示标题可用宋体；中央图形；说明靠近对象 | 暖白纤维画布，内部节点实体底色 | 保留参考图最鲜明的个人风格 |
| 素材库、知识工具、协作界面 | 无衬线控件；稳定工具栏；列表或表格 | 暖白实体表面，纹理局限于预览 | 信息多时减少容器，增加对齐 |
| 开发工作台、监控 | 无衬线，代码局部等宽；紧凑行列 | 中性灰白或独立深色 token | 借鉴 Vercel 的精度与状态表达 |
| 浮动工具栏、弹层 | 操作来源与展开层保持空间联系 | 实体底色为默认；必要时轻透明 | 借鉴 Apple 的功能层分离，不给内容卡片普遍加玻璃 |

暖纸与中性是表面选择，不要求用户换掉产品已有品牌。一个界面维持一种主材质；被展示的嵌入产品可有自己的局部配色。

工作台延续同一视觉语言：纸纹降到局部预览或关闭，内容区采用实体表面，强层次由明度、文字与边界建立。容器内部共享底色，跨对象才增加间距和边界。具体列表、导航、图标与密度方法见 [工作台与细节尺度](workbench.md)。

## 颜色

| 角色 | 原图实测 | GUI 建议 | 用途 |
| --- | --- | --- | --- |
| 画布 | 位图纹理，无单一 HEX | `#F5F2E9` | 暖纸底色；叠加原创纹理 |
| 实体面 | `#FBF8F1` | `#FBF8F1` | 节点、输入框、卡片 |
| 主文字 | `#1E1C19` | `#1E1C19` | 主要信息、强轮廓 |
| 次文字 | `#47423B` | `#47423B` | 正文说明 |
| 弱文字 | `#8F887D` | `#655F55` | 小字号说明采用更深的建议值 |
| 弱分隔 | `#D8D0C1` | `#D8D0C1` | 装饰性分组线，不能独自标识输入框 |
| 控件边界 | 按具体图形而异 | `#82796B` | 需要可辨识的可交互边界 |
| 视觉强调 | `#CF4436` | `#CF4436` | 图线、大字、选中标记 |
| 强调文字 | 同上 | `#A92F25` | 小字链接或浅红底上的强调文字 |
| 强调浅底 | `#F3D3CC` | `#F3D3CC` | 局部区域填充 |

原图的暖灰 `#8F887D` 对实体面 `#FBF8F1` 的对比度约 **3.31:1**，朱红 `#CF4436` 约 **4.37:1**。这解释了为什么图解里合适的颜色，缩成 UI 小字后需要调整。计算基于纯色；实际纹理还应检查最不利区域。

先用中性色建立层级，强调色集中于当前动作或焦点。约 5–10% 的视觉强调面积可作为首次排版的观察起点，遇到图表分类、品牌要求或警示信息时按语义调整，不把百分比当验收指标。

从其他产品借鉴强调手法时，先映射到 `--ad-accent`／`--ad-accent-text`；只有目标产品已有品牌或用户指定换色时才整体替换。类别身份、运行进度和结果判断分开表达，先用文字、形状与排布区分，再按真实任务需要引入语义色。分类标签不因来源里有多色调色板就全部着色。

深色模式独立设置背景、表面、文字、边界和强调色。暖纸不做颜色反转，纸纹默认关闭。图例仍保留线型与文字，成功和错误仍保留各自含义。

## 字体与字号

参考图的展示标题已转成 SVG path，只能从字形确认宋／明体风格，不能可靠识别字体名。真实产品采用可选择、可换行的文本。

- 中文展示：先用项目已授权的宋体；可选 `"Noto Serif SC", "Source Han Serif SC", "Songti SC", STSong, serif`。前两者需项目实际提供，不能假设已经加载。
- 英文展示：项目已有衬线字体或 `Georgia, serif`。中英混排分别观察字面大小、基线和字重。
- GUI：`system-ui, -apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`。Geist Sans 是可选的拉丁字体，不把中文降成缺字或不协调的回退。
- 代码：`ui-monospace, "SFMono-Regular", Consolas, monospace`。数据列可仅用 `font-variant-numeric: tabular-nums`。

| 角色 | 建议字号 | 行高 | 字重 |
| --- | --- | --- | --- |
| 图解展示标题 | 桌面 32–40px；窄屏 26–32px | 1.2–1.35 | 600–700 |
| 产品页面标题 | 24–32px | 1.25–1.4 | 600 |
| 区域标题 | 18–22px | 1.35–1.5 | 600 |
| 正文／表单 | 15–17px；移动输入至少 16px | 1.5–1.7 | 400 |
| 辅助文字 | 13–14px | 1.45–1.6 | 400 |

同一小组件通常只需标题、正文、辅助三个字号角色和常规／强调两个字重。复杂页面按信息层级扩展，而非把 Claude 的嵌入卡片约束机械套到所有产品。

中文默认字距 `0`；大字的视觉修整按字体单独检查。拉丁展示标题可试 `-0.02em`，不要把这个值施加到整个中文页面。长文宽度以约 28–38 个汉字为起点；表格按任务密度决定。

## 空间、边界与线条

图 1 的原始 SVG 是 `750 × 712`；水平分隔线从 x=40 到 x=710，左右留白各约 **5.3%**。节点轮廓为 2.4 个 SVG 单位，强调关系线为 3，弱关系线为 2.2，分隔线为 1.2。两组对象使用相同节点尺寸与基线。这些是视觉比例，不是所有屏幕的 CSS px。

网页实现以 4px 为基础间距步长，常用 8、12、16、24、32、48；组间留白明显大于组内留白。容器内边距从桌面 24–40px、窄屏 16–24px 起步。UI 细边框通常 1px，独立图形线条可 1.5–2px，关键关系线可 2–3px。

参考文章的 SVG 容器外圆角实测 6px。GUI 可用控件 6–8px、面板 10–12px；圆形用于节点、头像或有明确语义的状态。阴影表达浮起，平铺内容主要靠间距和分隔。

表格与长段落左对齐；数字比较列右对齐。标题居中适合独立图解，不自动扩展到每张工具卡片。分隔线只画一次，避免相邻半透明边框叠加变深。

## 纤维材质的实现

用户形容的“羊毛毡”在视觉上接近低对比纸纤维：细颗粒、短纤维和缓慢变化的明暗，不带明显方向性。原文使用栅格纹理作为 SVG 的第一层，不是已验证的实时毛发或 CSS 材质。

本技能的 `assets/fiber-tile.png` 是原创、可平铺的灰度纹理，混合多尺度噪声与短纤维。它不含参考文章图案或文字。`tokens.css` 将纹理绘制在独立伪元素上，正文在其上方，`pointer-events: none` 保持交互通畅。

在暖白底上用 `multiply` 混合，初始不透明度 0.08–0.18；工作界面可降到 0–0.06。保持背景纹理静止，按固定 CSS 尺寸平铺，避免随窗口拉伸纤维。远看应先读到内容，近看才看到材质。

不要对整张容器施加降低透明度或模糊的效果，否则文本和焦点环也会失去清晰度。导出静态图时可合成纹理与矢量图；交互界面保留文本、控件与背景分层。无需为此额外引入动效或绘图库。

## 可复用的视觉结构

| 关系 | 组织方法 | 交互迁移 |
| --- | --- | --- |
| 前后／两案比较 | 相同尺度并列；只强调差异；结论紧邻各自图形 | 切换前后或突出变化；窄屏竖排并保留同尺度 |
| 流程与接力 | 固定顺序和方向；标签贴近节点；当前步骤局部强调 | 显示当前／完成／失败；允许查看前一步；终态稳定 |
| 网络关系 | 节点样式一致；主关系实线；次关系虚线；图例先解释编码 | 选择节点显示相关边，同时提供可读的列表或摘要 |
| 数量比较 | 共享坐标、单位与尺度；直接标值；用一处强调目标 | 表格支持精确读取，图形支持快速比较；柱状图通常从零起 |
| 素材检索 | 工具栏、列表与预览分区；缩略图有区分；筛选靠近结果 | 筛选结果数即时更新；空结果能清除筛选；选择不移动焦点 |

图解的一次状态变化只承载一条因果关系。标题、图例和静态上下文保持稳定。核心结论在动画停止时仍可读，不能只闪现于某一帧。

## 动效与状态

以下时间是网页起点：按压反馈即时出现；颜色、边框与小范围反馈约 120–180ms；面板展开约 180–280ms。CSS 明确声明属性，避免 `transition: all`。普通按钮不为“高级感”统一缩放或弹跳。

手势跟随手指或指针，不等待结束才响应；松手后从当前位置延续，动画可被新输入中断。需要弹簧时优先使用项目已有能力，无手势的状态变化通常不需要物理模拟。

演示默认静止，由用户选择“下一步”或“播放”。播放期间有暂停／停止方式。减少动效时直接更新状态或短暂淡变；同时保留步骤说明。CSS 不能可靠关闭内嵌 SVG 的 SMIL，若沿用 SMIL，需单独管理其播放与静态终态。

实际产品异步状态由真实任务驱动，不添加伪进度或固定等待。演示样本使用的计时状态必须标为演示。等待不改变按钮宽度；失败保留输入并提供恢复动作；成功应靠近原动作反馈。

可点击目标建议至少 44 × 44 CSS px 以便触摸；紧凑桌面界面可按输入方式调整，但应保留清晰命中区。焦点环用独立的高对比 token，不能仅靠浅色外发光。用 Tab、Enter、Space 验证主要控件。
