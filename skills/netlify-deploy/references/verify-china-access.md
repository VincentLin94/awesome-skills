# 验证 Netlify 站点在国内网络可访问

沙箱环境不在国内,`curl -sI <url>` 返回 200 只能证明站点全球可达,不能直接证明国内可访问。用以下几种方式旁证国内可达性。

## 1. 国内公共 DNS 解析(最可靠的旁证)

用阿里云 DoH(国内节点)解析域名,能拿到 A 记录说明国内 DNS 层面正常:

```bash
curl -s "https://dns.alidns.com/resolve?name=<name>.netlify.app&type=A"
```

返回 `"Status":0` 且 `Answer` 里有 IP,说明国内 DNS 可正常解析(Netlify 边缘 IP)。这是判断"是否被 DNS 污染/阻断"的第一道信号——Vercel 的域名在国内常见解析异常或连接被重置,而 Netlify 通常正常。

## 2. 国内多节点在线探测(人工/浏览器)

把 URL 贴到以下国内探测平台,看各省节点 HTTP 状态:

- itdog.cn(站长工具 · 网站测速,多地 http 检测)
- 阿里云网站运维检测平台 boce.aliyun.com
- 站长之家 ping/http 检测 tool.chinaz.com

多数节点返回 200 即可确认国内可访问。这些站点多带 JS 挑战,脚本直连常拿不到结果,适合让用户在浏览器里点一下确认。

## 3. 直接让用户复验

最终以用户在国内真实网络下能打开为准。交付时可以直接说明:"Netlify 的 *.netlify.app 国内通常可直接访问,你在手机/电脑浏览器打开确认一下"。

## 结论口径

沙箱侧能确认的是:全球可达(200)+ 国内 DNS 正常解析。这两点满足时,国内可访问性有很高把握,但"绝对可访问"需用户真实网络最终确认。
